# 输入区与模型

## Sub-features

- 文本输入与 @ 文件补全
- 发送、停止、跟随消息（steer / follow-up）
- 模型与角色选择、思考级别、工具预设、压缩上下文
- 上下文用量指示、完成提示音开关、更多控制面板

## How to get to it (user POV)

页面底部固定输入区，`textarea` 是主输入框；右侧一排按钮依次是模型、角色、思考级别、工具、压缩与发送。

## Driving it with the browser harness

1. 选中一个会话或项目后，`textarea` 可聚焦并接受输入。
2. 输入一段文本，回车触发发送；发送期间出现停止按钮，气泡进入流式状态。
3. `[data-context-available="true"]` 表示上下文用量已上报；`[data-context-level]` 给出 normal / warning / critical。
4. 打开模型选择器，里面的筛选输入框可过滤模型列表；选择后顶栏或输入区显示的模型名应当变化。

验证默认不发送真实请求：会产生模型费用。需要确认发送链路时，先征得用户同意，或用一次极短提示。

## Gotchas

- 没有配置模型、或没有选中 cwd 时，发送不可用，属于配置问题而不是回归。
- 输入法组合输入期间回车不会发送，脚本发文字时先 `fill` 再按一次 `Enter`，不要逐字输入。
- 上下文用量在压缩刚结束时可能显示未知或 0，等一轮对话后再断言。
- 手机档的一排控件折叠进“更多”面板，命中区 44px，断言时用计算尺寸而不是截图像素。
