# 会话地图按轮现算

顶栏的「地图」把当前会话画成按轮聚合的树：一个节点是一轮用户提问连同其后的回答与工具调用，边来自条目的 `parentId`。fork 文件逐字复制父会话的条目，id 相同，所以跨文件合并时主干只出现一次，分支从切点长出去。

数据每次从 `.jsonl` 现算，按 mtime 与大小缓存，只有拖动过的卡片坐标写 `localStorage`。子代理会话（位于以父文件名命名的子目录下）不进图。切点取这一轮最后一个「没有未完成工具调用」的条目，避免新会话带着悬空 toolCall 开始。
