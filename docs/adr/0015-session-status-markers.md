# 会话状态标记与未读归属

侧栏每条会话只有一个标记。动态层有两个子状态：运行中是旋转的缺口圆环，等待用户回答是黄色完整圆环、呼吸、不旋转。静态层有五种结果：完成绿、中断黄、取消灰、报错红、待回复蓝，全部实心、无动画。动态优先，运行期间不显示静态标记。

标记由 `lib/session-marker.ts` 的纯函数解析；最后状态来自会话文件尾部，经 `lib/session-reader.ts` 透传。静态状态按 `STATIC_MARKER_APPEARANCE` 的实际键收窄，联合类型之外的值不产生标记。

归属规则：运行结束时，当前选中且页面可见的会话算已读；页面隐藏、别的会话结束、或服务失联期间结束的会话写入未读集合并亮标记。选中的运行同样进入结束列表，跳过只是归属判定。多次运行换算到同一会话时只保留一条记录，`isSelected` 按任一次 OR 合并。

未读集合由 `lib/session-unread.ts` 持有并写入本机存储。侧栏用 `useSyncExternalStore` 订阅；快照读取是纯读取，水合只发生在订阅与写入口。打开会话时清零：侧栏点击、会话地图命令面板、通知点击汇合到 `AppShell.handleSelectSession()`；URL 启动恢复自行清零，工作区自动恢复不算点开。会话再次运行先清旧标记，结束后按新结果重新亮。

首次播种只加异常存量（中断、取消、报错、待回复），每个浏览器一次，排在初始恢复落定之后，并排除当前打开与启动会话。项目行未读角标统计未读集合，静态标记一并计入，不按颜色拆分。重启对账用 `ompdesk:running-session-ids` 对比首轮快照，走同一归属函数，排在恢复落定之后。

## 后果

标记表达最近一次落盘结果，不跟随会话内分支切换；切到历史分支后仍按文件末尾判定。
