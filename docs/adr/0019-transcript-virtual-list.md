# 转写是虚拟列表，条目以一轮为单位

会话转写交给 `react-virtuoso`，它只挂载可见范围，首屏定位到最后一条并对齐视口底部，挂载量与会话长度无关。首屏起点在列表挂载时读一次，之后条目增减不重设，短会话仍从顶部排下来。

分组由 `lib/transcript-items.ts` 一次性算出扁平条目数组并缓存，列表只消费结果，不参与判定。一个条目覆盖一段连续消息：锚点（用户消息或 Compaction 摘要）、可见过程消息、正式回答、正式回答之后的尾部。没有正式回答的一轮与运行中的最后一轮按消息逐条渲染，`isStandalone` 决定界面是否折叠过程组，分组判定本身不变。

流式消息没有 entryId，不能参与分组，由 `lib/transcript-live-tail.ts` 作为固定键的合成项接在条目数组末尾；没有流式消息时原数组引用不变，只有末尾这一项随数据块重建。

展开状态与延迟内容是否已取回不存在组件内部：`lib/transcript-view-state.ts` 按「会话 id + 本轮锚点 entryId + 部位标识」保存，条目滚出视野被卸载后重建仍是用户最后一次的选择。思考块取回内容后标记已加载，重建时直接落到非加载态，不再重放加载过程。没有会话 id 的新会话共用一个空桶。

滚动跟随用列表自己的跟随输出，开关由既有的「自动跟随 / 用户上滚」状态给出；用户上滚即关闭跟随。「跳到最新」滚到列表末尾，跳转用列表的「滚到第 N 项」，不自行换算像素。

提问跳转条与列表并列，贴在 820px 对话列左外侧的 36px 车道，绝对定位、不参与布局。它拿同一份条目数组挑出带提问的锚点，圆点数据不重新扫描消息；当前轮由列表报告的顶部可见条目决定。圆点为 6px、中心距 14px，容器最高 180px，超出后容器内部滚动并把当前圆点滚到正中。对话区域用容器查询按自身宽度收缩：留给跳转条的车道不足时（`< 900px`）整条隐藏，移动档媒体查询再隐藏一次，两条都在首帧生效。

列表不嵌套第二层虚拟化；工具输出、代码块、图片、展开收起都由列表测量高度，不预设固定高度。会话地图与跳转条各司其职，地图不入列表。
