# 右侧面板是一个标签页面

顶部按钮展开的右侧面板只有一层标签，默认没有任何标签，正文列出「文件浏览器」与「子代理」两个入口。头部左侧的两个入口按钮把对应视图作为固定视图标签打开，再点一次收起；从文件浏览器点开文件新增一个文件标签，同一路径复用同一个标签。标签集合与激活项都在 `components/AppShell.tsx`，标签的 id、文案键、图标集中在 `lib/panel-tabs.ts` 与 `components/PanelViewIcon.tsx`，标签栏、头部入口与空页入口共用。

全部标签按 id 保持挂载，只切换 `display`。折叠的文件夹、文件滚动位置与子代理的选中项因此不随切换丢失。

「可见」由 `tab.id === activePanelTabId && rightPanelOpen` 决定，传给标签正文的 `active`。文件标签只在可见时连接 watch 的 SSE 并注册选区快捷键；切回时重新连接，`connected` 事件带回 mtime 与大小，文件未变则沿用缓存内容。子代理标签同样只在可见且子代理运行时每秒补拉，重新可见或运行结束时补读一次尾部。面板关闭时整个 `#file-panel` 置为 `inert`，残留控件不进入焦点序列。

子代理不再占据聊天区右侧的常驻栏，只在标签打开时可见。运行中的数量显示在三处：面板开关、子代理标签与空页入口。

切换项目清空全部标签并回到空页，面板保持打开。同一仓库的 worktree 之间不算切换，标签保留。
